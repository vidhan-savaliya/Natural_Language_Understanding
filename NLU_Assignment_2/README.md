This repository contains the complete implementation for NLU Assignment 2, divided into two main problems.

## Prerequisites

All dependencies for both problems are listed in the common `requirements.txt`. Install them using:

```bash
pip install -r requirements.txt
```

---

## 1. Problem 1: Learning Word Embeddings from IIT Jodhpur Data

**Directory**: `M25CSA031_Prob1`

This folder contains the code for crawling the IIT Jodhpur domain, cleaning the text data, and training Word2Vec models (both from scratch and using Gensim).

Please navigate to the `M25CSA031_Prob1` directory and refer to its specific **`README.md`** for detailed step-by-step run instructions.

---

## 2. Problem 2: Character-Level Name Generation

**Directory**: `M25CSA031_Prob2`

This folder contains the implementation of sequence models completely from scratch (Vanilla RNN, BLSTM, RNN + Attention) to generate Indian names.

Please navigate to the `M25CSA031_Prob2` directory and refer to its specific **`README.md`** for detailed step-by-step run instructions.
